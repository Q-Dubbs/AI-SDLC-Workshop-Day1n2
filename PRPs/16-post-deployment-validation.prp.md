# PRP-16: Post-Deployment Validation

## Objective
Run production validation against functional, performance, security, browser, and documentation criteria.

## Scope
- Functional runbook for all 11 features in production
- Lighthouse/perf verification including slow network test
- Security checks: HTTPS, cookie flags, protected routes, injection/XSS checks
- Browser matrix verification (desktop/mobile)
- Documentation completion (`README`, env vars, known issues, changelog)

## Scoring Model
- Feature completeness: /110
- Testing: /30
- Deployment: /30
- Quality & performance: /30
- Final: /200

## Exit Criteria
- Minimum target: MVP complete
- Stretch target: Production Ready / Excellent bands
